# Website

The homepage and privacy policy for CigMail's Google OAuth app (Google Auth Platform → Branding).
Live at <https://ciger.dev/cigmail/> and <https://ciger.dev/cigmail/privacy/>.

Plain static HTML, no build step. To deploy, copy the contents of this folder to the `cigmail/`
folder of the web root that serves `ciger.dev`.

If you run your own OAuth app, host these pages on your own domain and change the contact address.
